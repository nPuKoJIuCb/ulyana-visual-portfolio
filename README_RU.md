## Четыре авторских кейса

### 01. MURA Object Editions

Предметная коллекция: статуэтка, коллекционная банка для мёда, брелки и подарочный объект, связанные единым силуэтом и системой материалов.

![Коллекционная банка для мёда MURA](public/images/mura-honey-jar.webp)

### 02. TAMYR Botanical Tea

Концепция упаковки ботанического чая: два направления, выбранный маршрут, лицевая и оборотная этикетки, визуализация и честные границы готовности к печати.

![Упаковка TAMYR Botanical Tea](public/images/tamyr-tea-hero.webp)

### 03. SAULE Coffee House

Презентационная система на 12 слайдов: один аргумент на слайд, ясный сценарий и последовательная визуальная логика.

![Презентация SAULE Coffee House](public/images/saule-coffee-hero.webp)

### 04. QADAM Learning Studio

Система из девяти контент-шаблонов, которая сохраняет узнаваемость при смене темы, сообщения и формата.

![Шаблоны QADAM Learning Studio](public/cases/qadam-learning/previews/qadam-template-grid.webp)
